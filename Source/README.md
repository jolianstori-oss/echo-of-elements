# Source

يحتوي هذا المجلد على كود C++ الخاص بلعبة **Echo of Elements**. توجد وحدة `EchoOfElements` داخل المجلد الفرعي المقابل، وتشمل ملف قواعد البناء، نقطة دخول الوحدة، وملفي Target للعبة والمحرر.

يُفترض أن تُضاف الأنظمة المستقبلية، مثل الشخصيات وقدرات العناصر ووسوم Gameplay، إلى مجلدات `Public` و`Private` داخل الوحدة مع الحفاظ على فصل الواجهات عن التنفيذ.
