# Content

يحتوي هذا المجلد على الأصول الثنائية والمحتوى الذي ينشئه محرر Unreal Engine. يتضمن الهيكل الحالي مجلد `Maps/` للخرائط ومجلد `Input/` لأصول Enhanced Input المستقبلية.

لم تُنشأ ملفات `.uasset` أو خرائط فعلية في هذه المرحلة؛ لذلك تُشير إعدادات المشروع إلى المسارات المستهدفة `/Game/Maps/Echo_Main` و`/Game/Maps/Echo_Transition` كي تُنشأ لاحقاً داخل المحرر.
