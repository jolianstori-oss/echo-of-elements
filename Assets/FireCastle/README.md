# حزمة قلعة الجمر — Fire Castle

> **الحالة:** ملفات مصدرية ومعاينات ووثائق مستوردة؛ لم يتم اعتماد استيرادها أو اختبارها داخل Unreal Editor بعد.

## الغرض

يجمع هذا المجلد جميع الملفات المرفقة الخاصة بمرحلة **قلعة الجمر** داخل مسار ثابت وقابل للمراجعة. يحتفظ المشروع بالحزمتين كما وصلتا، ويقدّم نسخة مفكوكة من حزمة الخامات النهائية للمراجعة والاستيراد اليدوي. لا يُنفّذ أي سكربت موجود في الحزمة تلقائياً.

| المسار | المحتوى | الاستخدام |
| --- | --- | --- |
| `Packages/FireCastle3D_Pack_FinalMaterials.zip` | الأرشيف الأصلي لحزمة الخامات النهائية | حفظ مصدر التسليم كما ورد والتحقق من سلامته عند الحاجة. |
| `Packages/FireCastle3D_Pack.zip` | الأرشيف الأصلي للحزمة الأساسية | مرجع للنسخة السابقة أو البديلة. |
| `SourcePackage/StaticMeshes/` | نماذج FBX ثابتة | استيراد يدوي إلى المسار المقترح لـStatic Meshes بعد مراجعة المقياس والمحاور والـUV والتصادم. |
| `SourcePackage/SkeletalMeshes/` | نماذج FBX هيكلية | استيراد يدوي مع Skeleton وPhysics Asset وخطة مواد صريحة. |
| `SourcePackage/Textures/` | خرائط PBR | استيراد مضبوط حسب دور الخريطة، لا عبر مواد FBX التلقائية. |
| `SourcePackage/GLB/` | نسخ GLB مرجعية | معاينة أو نقل محتمل؛ لا تحل محل FBX في مسار Unreal المعتمد. |
| `SourcePackage/Previews/` | معاينات مرئية | مراجعة بصرية قبل الاستيراد. |
| `SourcePackage/Source/Blend/` | ملفات Blender المصدرية | تعديل المصدر وإعادة التصدير فقط مع توثيق التغيير. |
| `SourcePackage/Source/UnrealPython/` | نصوص مساعدة للاستيراد | تُراجع وتُشغّل فقط في نسخة عمل من المشروع وبعد موافقة صريحة. |
| `SourcePackage/Documentation/` | فهرس أصول وتقارير QA | مرجع مساعد، وليس إثباتاً لاختبار داخل المحرك. |
| `Previews/UserSupplied/` | معاينات PNG مرفقة منفصلة | حفظ مطابق للملفات المنفردة الواردة من المستخدم. |

## مسار الاستيراد المقترح

تستهدف الحزمة هيكل Unreal الآتي. أنشئ المجلدات داخل `Content/` عبر محرر Unreal، واستورد الملفات المناسبة ولا تنسخ ملفات FBX أو PNG إلى `Content/` بوصفها بديلاً عن الاستيراد.

```text
/Content/EchoOfElements/Stage1/FireCastle/
├── Meshes/Static/
├── Meshes/Skeletal/
├── Materials/
│   ├── Textures/BaseColor/
│   ├── Textures/Normal/
│   ├── Textures/ORM/
│   ├── Textures/Height/
│   ├── Textures/Emissive/
│   └── Instances/
└── Blueprints/
```

## قائمة فحص الاستيراد

قبل اعتماد أي أصل، تأكد من أن بيانات المصدر تسمح بالاستخدام ضمن المشروع، وأن الأصل استُورد في نسخة عمل قابلة للرجوع. افحص المقياس، المحاور، الـUV، التصادم، الـLOD، والمادة الافتراضية لكل Mesh. يجب أن تكون خرائط Base Color وEmissive بـ` sRGB = On`، بينما تكون Normal وORM وHeight بـ`sRGB = Off`؛ تستخدم Normal ضغط **Normalmap**، وتستخدم ORM ضغط **Masks**، وتستخدم Height ضغط **Grayscale**. التفاصيل الكاملة في [دليل خامات قلعة الجمر](../../docs/stages/fire-castle/Fire-Castle-Final-Materials-Guide.md).

بعد الاستيراد، اختبر الأصل في خريطة المرحلة عند مسافة الكاميرا الفعلية. يجب أن تظل مناطق الخطر الناري ونقاط الأمان والتفاعلات والمقذوفات واضحة بصرياً، وألا تكون المادة المنبعثة أو إعداد Bloom هي العلامة الوحيدة على حالة اللعب.

## التتبع والترخيص

يوثّق هذا المجلد موضع الملفات فقط؛ لا يثبت ملكية فكرية أو ترخيصاً أو جاهزية إنتاج. قبل إعادة استخدام أي ملف في بناء قابل للنشر أو مادة تسويقية، أضف مصدره وحقوق استخدامه والمالك وحالة القبول في سجل الأصول أو وثيقة قرار مناسبة.
