# صدى الأثير — موجز المشروع

**الإصدار:** 0.1.0-preproduction  
**المحرك المستهدف:** Unreal Engine 5.8  
**نوع الحزمة:** تحضير هندسي ووثائقي خارج المحرك  
**المالك الافتراضي للوثائق:** Manus AI

## 1. الغرض

«صدى الأثير» هو الاسم العامل لمشروع لعبة سردية ثلاثية الأبعاد تركز على الاستكشاف، قراءة الإشارات الصوتية، وفكّ طبقات ذاكرة مكان غامض. هذه الوثيقة تثبّت افتراضات أولية قابلة للتعديل، ولا تدّعي أن أي قرار إبداعي نهائي ما لم يُعتمد لاحقاً في سجل القرارات.

## 2. حدود العمل الحالية

يشمل هذا المسار إعداد هيكل مشروع قابل للنقل، توصيف الأنظمة، قواعد التسمية، سجل الأصول، خارطة الإنتاج، وقوائم التحقق. لا يشمل تشغيل Unreal Engine، أو إنشاء مشروع فعلي من خلال المحرك، أو استيراد أصول، أو اختبار Play-In-Editor، أو تنفيذ Blueprints/C++ داخل المحرك.

| المجال | القرار الأولي | حالة القرار |
|---|---|---|
| المنظور | منظور شخص ثالث | افتراض قابل للمراجعة |
| النمط | مغامرة سردية واستكشاف | افتراض قابل للمراجعة |
| المنصات | الحاسب الشخصي أولاً | افتراض إنتاجي |
| أسلوب اللعب الأساسي | حركة، تفاعل، التقاط إشارات، ألغاز بيئية | مسودة |
| الحفظ | حفظ تلقائي عند نقاط سردية | مسودة |
| الاتصال | تجربة فردية غير متصلة | افتراض |
| اللغة | العربية كلغة عرض أولى، مع قابلية التوطين | قرار نطاق |
| الرسوم | بيئة واقعية stylized-realistic منخفضة التشبع | اتجاه فني |

## 3. مبادئ التصميم

تقوم التجربة على أن **الصوت دليل قابل للتفسير وليس مجرد مؤثر جوي**. ينبغي أن تكافئ اللعبة الملاحظة، وأن تجعل كل إشارة ذات وظيفة سردية أو ميكانيكية واضحة. يجب أن تكون الألغاز قابلة للفهم من خلال البيئة نفسها، مع تجنب الاعتماد على واجهة مزدحمة أو تعليمات طويلة.

> كل نظام يدخل اللعبة يجب أن يخدم واحداً على الأقل من ثلاثة محاور: كشف العالم، تعميق الشخصية، أو توجيه اللاعب نحو قرار ذي معنى.

## 4. المخاطر المبكرة

أكبر خطرين هما تضخم نطاق المحتوى الصوتي، وتعقيد ربط الإشارات السمعية بالمنطق السردي. لذلك تُعامل منظومة الأثير كطبقة بيانات قابلة للتوسعة، وتُفصل عن منطق الحركة والتفاعل والحفظ. كما يجب اعتماد نموذج أولي ورقي ووثائقي قبل أي تنفيذ.

## 5. معيار الجاهزية للانتقال إلى التنفيذ

لا ينتقل المشروع إلى مرحلة التنفيذ داخل المحرك إلا بعد اعتماد وثيقة التصميم العام، وتثبيت خريطة الحلقة اللعبية، وإكمال سجل الأنظمة، وتعريف أول منطقة اختبار، وربط كل أصل مخطط بمالك وحالة وقرار قبول.

## 6. المصطلحات

| المصطلح | التعريف |
|---|---|
| الأثير | طبقة الإشارات السمعية/المكانية التي تكشف آثاراً أو ذكريات أو توجيهات |
| الصدى | نتيجة إدراك إشارة أثيرية وإعادة تفسيرها داخل العالم |
| العقدة | نقطة بيانات أو تفاعل يمكن أن تغيّر حالة السرد أو البيئة |
| الحلقة اللعبية | الاستكشاف ← الالتقاط ← التفسير ← التفاعل ← كشف جديد |
