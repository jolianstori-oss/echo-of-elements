# مواصفة إقلاع المشروع

هذا الملف يحدد ما ينبغي إنشاؤه عند بدء التنفيذ الفعلي داخل Unreal Engine 5.8، ولا يمثل عملية إنشاء أو تشغيل تمت حالياً.

## ملفات الإعداد المستهدفة

| الملف | الغرض |
|---|---|
| `SadaAlAthir.uproject` | تعريف المشروع والوحدات والمكوّنات المعتمدة |
| `Config/DefaultEngine.ini` | renderer، الصوت، الإدخال العام، الخرائط الافتراضية |
| `Config/DefaultGame.ini` | GameMode، مسارات الحفظ، إعدادات التوطين |
| `Config/DefaultInput.ini` | الحركة، التفاعل، الإدراك، القائمة |
| `Config/DefaultEditorPerProjectUserSettings.ini` | تفضيلات الفريق غير الحساسة |

## قرارات الإقلاع المقترحة

ينبغي أن يبدأ المشروع بخريطة اختبار صغيرة منفصلة عن أول منطقة سردية. يجب تعريف نقطة دخول واضحة، وGameMode واحد للنموذج الأولي، وطبقة بيانات قابلة للتوسع. لا تُضاف إضافات خارجية قبل تسجيل سبب الحاجة، أثرها على التوافق، وخطة استبدالها.
