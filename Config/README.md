# Config

يحتوي هذا المجلد على إعدادات مشروع **Echo of Elements** الخاصة بالمحرك واللعبة والإدخال. يحدد `DefaultEngine.ini` إعدادات الرندر والفيزياء والشبكة وخرائط التشغيل، بينما يحدد `DefaultGame.ini` بيانات المشروع والإعدادات العامة للخرائط. يضم `DefaultInput.ini` خرائط الحركة والهجوم والامتصاص والتفاعل.

تُقرأ هذه الملفات تلقائياً عند فتح ملف `EchoOfElements.uproject` في Unreal Engine 5.8. لا تُخزّن هنا الملفات المولدة أو الحالة المحلية للمحرر.
