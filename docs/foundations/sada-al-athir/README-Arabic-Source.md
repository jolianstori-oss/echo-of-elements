# صدى الأثير

حزمة التحضير الهندسي والوثائقي لمشروع لعبة مستهدف لـ **Unreal Engine 5.8**.

هذه الحزمة لا تحتوي على تنفيذ داخل المحرك. الغرض منها تثبيت النطاق، المعمارية، بنية المجلدات، سجل الأصول، وخطة الانتقال إلى التنفيذ لاحقاً.

## نقطة البداية

ابدأ بقراءة الملفات بالترتيب التالي:

| الترتيب | الملف | الغرض |
|---|---|---|
| 1 | `docs/00-project-brief.md` | النطاق والافتراضات والمصطلحات |
| 2 | `docs/game-design-document.md` | الرؤية والحلقة اللعبية |
| 3 | `architecture/technical-architecture.md` | الأنظمة والبيانات والاتصال |
| 4 | `architecture/project-structure.md` | مجلدات المشروع وقواعد التسمية |
| 5 | `planning/production-roadmap.md` | مراحل الإنتاج وبوابات الانتقال |
| 6 | `content_manifest/asset-register.md` | سجل الأصول الأولي |
| 7 | `planning/decision-log.md` | القرارات المفتوحة والمثبتة |

## مبدأ التعامل مع هذه الحزمة

تُعد الملفات الحالية **مسودة تأسيسية**. أي اعتماد نهائي يجب أن يحدّث الحالة في سجل القرارات، ويضيف مالكاً ومعيار قبول، ويربط التغيير بالوثيقة المتأثرة.

## نطاق التسليم الحالي

تم إعداد بنية المجلدات والوثائق وقوالب الإعداد فقط. لم يُفتح المحرك، ولم تُنشأ خرائط أو Blueprints أو أصول داخل Unreal Engine.
